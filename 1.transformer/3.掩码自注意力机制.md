# 掩码自注意力机制
掩码自注意力，即 Mask Self-Attention，是指使用注意力掩码的自注意力机制。掩码的作用是遮蔽一些特定位置的 token，模型在学习的过程中，会忽略掉被遮蔽的 token。

使用注意力掩码的核心动机是让模型只能使用历史信息进行预测而不能看到未来信息。使用注意力机制的 Transformer 是对一个文本序列，不断根据之前的 token 来预测下一个 token，直到将整个文本序列补全。

例如，如果待学习的文本序列是 【BOS】我 爱 打 魔兽世界【EOS】，那么，模型会按如下顺序进行预测和学习：（【bos】在模型词表中表示开始，【EOS】表示结束，即模型如果预测到下个词是【EOS】就不会再继续预测了）  

```python
Step 1：输入 【BOS】，输出 我
Step 2：输入 【BOS】我，输出 爱
Step 3：输入 【BOS】我 爱，输出 打
Step 4：输入 【BOS】我 爱 打，输出 魔兽世界
Step 5：输入 【BOS】我 爱 打 魔兽世界，输出 【EOS】
```
可以看到，这一句话预测完要5个步骤，很慢，所以大佬想出了掩码机制，让其可以并行计算，一次就可以计算出结果了。掩码自注意力会生成一串掩码，来遮蔽未来信息
```python
<BOS> 【MASK】 【MASK】 【MASK】 【MASK】  【MASK】
<BOS>    我    【MASK】 【MASK】 【MASK】  【MASK】
<BOS>    我      爱     【MASK】 【MASK】  【MASK】
<BOS>    我      爱       打     【MASK】  【MASK】
<BOS>    我      爱       打      魔兽世界 【MASK】
<BOS>    我      爱       打      魔兽世界   <EOS>
```
这个掩码矩阵是一个上三角矩阵，【mask】部分会赋值为负无穷，非【mask】部分赋值为0，为什么要这么赋值呢，因为会用这个掩码矩阵与上一章计算的注意力权重矩阵也就是$QK^T$逐元素相加，再将这个结果进行softmax，可想而知，【mask】的部分softmax的结果就非常接近0，也就是没有分配权重，而非【mask】部分由于是0，所以相加后保持不变。

总而言之，mask self-attention就是在模型训练阶段进行加速用的，一句话一次头输入给模型，只需要一步就能计算出这句话的损失，而在推理阶段，就是正常的一个字一个字的输入了（配合KV Cache后面再说）。
