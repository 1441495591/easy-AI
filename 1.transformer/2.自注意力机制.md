## softmax
softmax的公式我就不列啦，感兴趣可以自己查一下，比较简单，不知道的童鞋也不用特地去看，只要知道这个函数就是将向量输出成概率分布的，是一种归一化函数。  
如：现在有一个向量 $\vec{v}$ = [a1, a2, a3, a4]  
$softmax(\vec{v}) = [0.1, 0.2, 0.1, 0.6]$  
结果中所有元素之和为1，里面的每个元素就表示概率

## transformer中的自注意力机制
这里我引用 https://github.com/datawhalechina/happy-llm 仓库中的第二章中关于注意力机制的说明，我觉得是说的比较清晰的。而在自然语言处理领域，我们往往也可以通过将重点注意力集中在一个或几个 token，从而取得更高效高质的计算效果。  

注意力机制有三个核心变量：Query（查询值）、Key（键值）和 Value（真值）。我们可以通过一个案例来理解每一个变量所代表的含义。例如，当我们有一篇新闻报道，我们想要找到这个报道的时间，那么，我们的 Query 可以是类似于“时间”、“日期”一类的向量（为了便于理解，此处使用文本来表示，但其实际是稠密的向量），Key 和 Value 会是整个文本。通过对 Query 和 Key 进行运算我们可以得到一个权重，这个权重其实反映了从 Query 出发，对文本每一个 token 应该分布的注意力相对大小。通过把权重和 Value 进行运算，得到的最后结果就是从 Query 出发计算整个文本注意力得到的结果。  

刚刚我们说到，注意力机制有三个核心变量：查询值 Query，键值 Key 和 真值 Value。首先，我们有这样一个字典：
```python
{
    "apple":10,
    "banana":5,
    "chair":2
}
```
此时，字典的键就是注意力机制中的键值 Key，而字典的值就是真值 Value。假设现在我们需要从这个字典中找到"fruit"，那么"fruit"就是Query，很明显，从我们人类的角度来看，答案是10和5的结合(具体还要看上下文，假如是猴子，那可能5的比重会更大)，反正不可能是2。那注意力机制是怎么计算的呢？  
我们可以为三个Key赋予如下的权重：  
```python
{
    "apple":0.6,
    "banana":0.4,
    "chair":0
}
```
那么，我们最终查询到的值应该是：
$Value = 0.6*10 + 0.4*5 + 0*2 = 8$  

给不同 Key 所赋予的不同权重，就是我们所说的注意力分数，也就是为了查询到 Query("fruit")，我们应该赋予给每一个 Key 多少注意力。但是，如何针对每一个 Query，计算出对应的注意力分数呢？从直观上讲，我们可以认为 Key 与 Query 相关性越高，则其所应该赋予的注意力权重就越大。

之前我们讲到过词向量，我们可以将Query和所有的Key都转为词向量，然后计算这个Query向量和每个Key向量的相似度，这里就用到了向量的点积，点积的结果就是相似度，我们把所有Key向量放在一起成为一个K矩阵，  
$x = Query*K^T$  
x的结果就是Query对K矩阵中每个key向量的相似度，然后再通过softmax函数进行归一化得到概率分布，就会获得类似[0.6, 0.4, 0]这样的结果。这样，得到的向量就能够反映 Query 和每一个 Key 的相似程度，同时又相加权重为 1，也就是我们的注意力分数了。最后，我们再将得到的注意力分数和值向量做对应乘积即可，就是上面我们得到8的结果的过程。根据上述过程，我们就可以得到注意力机制计算的基本公式：  
$$
\operatorname{attention}(Q, K, V) = \operatorname{softmax}(qK^T)v
$$  
不过，此时的值还是一个标量，同时，我们此次只查询了一个 Query。我们可以将每个值转化为维度为 $d_v$ 的向量拼成矩阵V，同时一次性查询多个 Query，同样将多个 Query 对应的词向量堆叠在一起形成矩阵 Q，得到公式：  
$$
Z = \operatorname{attention}(Q, K, V) = \operatorname{softmax}(QK^T)V
$$  
最后结果就是一个新的包含了注意力权重的向量表征的矩阵，Z中的每一行向量对应了Q的这一行的词向量经过与所有的K、V矩阵中每一行向量进行注意力计算后的包含全局信息的新的词向量。感觉说的比较啰嗦，反正Z矩阵中就是新的包含更多信息的每个词的词向量了，用这个比用一开始的QKV中的词向量效果要好。我来举个例子吧！  

现有一句话：我爱打魔兽世界  
第一步还是分词嘛，我、爱、打、魔兽世界，然后转为词向量q、k、v
| 位置 | Token | Query | Key | Value |
| --- | --- | --- | --- | --- |
| 1 | 我 | q1 | k1 | v1 |
| 2 | 爱 | q2 | k2 | v2 |
| 3 | 打 | q3 | k3 | v3 |
| 4 | 魔兽世界 | q4 | k4 | v4 |

| Q → K | 我(k1) | 爱(k2) | 打(k3) | 魔兽世界(k4) |
| --- | --- | --- | --- | --- |
| 我(q1) | q1·k1 | q1·k2 | q1·k3 | q1·k4 |
| 爱(q2) | q2·k1 | q2·k2 | q2·k3 | q2·k4 |
| 打(q3) | q3·k1 | q3·k2 | q3·k3 | q3·k4 |
| 魔兽世界(q4) | q4·k1 | q4·k2 | q4·k3 | q4·k4 |

| Q → K | 我 | 爱 | 打 | 魔兽世界 |
| --- | --- | --- | --- | --- |
| 我 | α11 | α12 | α13 | α14 |
| 爱 | α21 | α22 | α23 | α24 |
| 打 | α31 | α32 | α33 | α34 |
| 魔兽世界 | α41 | α42 | α43 | α44 |

| Token | 输出 |
| --- | --- |
| 我 | z1 = α11 v1 + α12 v2 + α13 v3 + α14 v4 |
| 爱 | z2 = α21 v1 + α22 v2 + α23 v3 + α24 v4 |
| 打 | z3 = α31 v1 + α32 v2 + α33 v3 + α34 v4 |
| 魔兽世界 | z4 = α41 v1 + α42 v2 + α43 v3 + α44 v4 |  

就是每一个q去乘上每一个k，得到的每一个权重去乘上这个k对应的v，得到了这个词的新的向量表示。可以看到有很多步骤，实际中是拼成矩阵进行并行运算的，也就是  
$$
\operatorname{softmax}(QK^T)V
$$ 

最后总结个现象，大家有没有发现KV是绑定的，K是名称，V是具体的值，他俩是同源的，但是Q可以是同源的(上面的例子是同源的)，也可以是其他任何转为了向量的东西，可以是文字可以是图片可以是音频等等，所以我们把Q与KV同源的叫做自注意力，不同源的叫做跨注意力。
